# harness/ · PC 侧实验框架（M4'）

研究实验的驱动与采集层。**仅实验时需要 PC**（经 `adb reverse` 连接手机内核的回环 HTTP）；产品运行完全脱离 PC。

## 职责

1. **4 组对照条件**（预注册 §5.2）：A 冷启动 / B 自学蒸馏注入 / C 人类示教注入 / D 消融开关。
2. **状态重置**：`adb shell pm clear`、重装测试 App、分屏布局固定。
3. **任务集管理**：15 任务 × 3 难度层，随机顺序执行（抗顺序效应与中断）。
4. **指标采集**：完成率 / 步数 / 墙钟 / token（沿用 K2 三实体一致率信号口径）；对拍用例（Accessibility 桥 vs u2 同任务轨迹比对）。
5. **异常恢复**：u2/atx-agent 断连重连、无障碍健康检查、失败 run 原地重试标记。
6. **注入快照固化**：B/C 组使用固定知识快照；实验期间冻结 Curator 触发。
7. **示教录制器**（对照组 C 输入）。
8. **统计与出图**：vendor 桌面版 `scripts/effectiveness.py` 思路，判据按预注册 v1.2（完成率 ≥10pp 主判据）。
